In this Part you write the small, sharp tools that senior PCIe/NVMe engineers keep in their personal toolbox: a config-space parser, a TLP header decoder, SQE and CQE decoders, a PRP walker, a transaction timeline builder, a CID correlator, missing-completion and completion-timeout detectors, and an AER log analyzer. 72 Programming Labs 1–5: Parsers and Decoders

72.1 Why this chapter exists

Analyzer software decodes for you — until it does not: a new spec revision, a vendor-specific field, a log line, a customer's hex paste in an email, or a capture exported to CSV. The engineer who can turn bytes into meaning with twenty lines of code is never blocked. Writing the decoder also forces you to know every field boundary, which is the real point.

  • Beginner: run each lab, read its output, and match fields with the specification tables from earlier Parts.
  • Intermediate: modify the decoders (add a capability, a status code, an opcode) and feed them your own data.
  • Advanced: use the decoders as building blocks for the timeline tools of Chapter 73.
  • Senior: explain the safety boundaries: which code touches hardware (none here), which parses offline, which simulates.
  • Validation: turn each decoder's checks (alignment, malformed fields) into automated assertions on captured data.

Prerequisites: Python 3.8+, comfort with bit shifts and masks; Chapter 69; the TLP, SQE, CQE and PRP chapters earlier in the book.

⚠️ Safety boundary

None of these programs open /dev/mem, mmap resource0, write config, or issue NVMe passthrough commands. Do not "extend" them to do so. Writing to controller registers or doorbells from user space while the kernel driver owns the device corrupts queue state and can lose data. A script that safely drives a controller from user space (e.g. through VFIO) must be designed for it, own the device exclusively, and be run on a lab machine with a scratch drive — that is outside the scope of these labs.

🧒 Kid analogy

A secret-decoder ring: the letters of a coded message are just bytes; the ring tells you which letters go together and what they mean. These labs are you building the decoder ring yourself, so you can read any message, even ones the shop-bought ring does not know.

🧩 Where the analogy breaks

A decoder ring is always right. Your decoder is only as right as your reading of the specification — and the bytes may themselves be corrupt, truncated, byte-swapped or from a different spec revision. Good decoders validate and warn, not just print.

🧪 Lab 1 — Parse PCIe configuration-space hex SAFE

Classification: offline parsing · non-destructive · production-safe. File: lab01_cfgspace.py.

Objective: decode a Type 0 header, BARs, the capability chain (PM, MSI-X, PCI Express) and the extended chain (AER) from lspci -xxx/-xxxx text.

Setup: Python 3. Optional real input: sudo lspci -s 01:00.0 -xxxx > dev.hex (read-only).

Key ideas: config space is little-endian; capability pointers are byte offsets with the low two bits reserved; the standard chain lives below 100h and the extended chain starts at 100h with 32-bit headers (ID 15:0, version 19:16, next 31:20); a loop guard prevents a corrupt chain from hanging the parser; BAR sizes cannot be read from a dump because sizing requires writing all-ones — the parser deliberately never does that.

#!/usr/bin/env python3
"""Lab 1 - Parse PCIe configuration-space hex (OFFLINE PARSING, read-only).

Input : text in the format printed by `lspci -xxx` / `lspci -xxxx`
        ("OFF: b0 b1 ... b15"). Missing rows are treated as zero.
Output: decoded Type 0 header, BARs, capability chains, link status.
The script never touches hardware. Feed it a saved file:
        sudo lspci -s 01:00.0 -xxxx > dev.hex   # read-only, needs root
        python3 lab01_cfgspace.py dev.hex
"""
import sys, struct

SAMPLE = """\
000: cd ab 01 00 06 04 10 00 01 02 08 01 00 00 00 00
010: 04 00 60 fe 00 00 00 00 00 00 00 00 00 00 00 00
020: 00 00 00 00 00 00 00 00 00 00 00 00 cd ab 01 00
030: 00 00 00 00 40 00 00 00 00 00 00 00 0b 01 00 00
040: 01 50 03 00 08 00 00 00 00 00 00 00 00 00 00 00
050: 11 70 20 80 00 20 00 00 00 30 00 00 00 00 00 00
070: 10 00 02 00 c2 8f 00 10 30 20 00 00 44 0c 00 00
080: 40 00 43 10 00 00 00 00 00 00 00 00 00 00 00 00
090: 00 00 00 00 10 00 00 00 00 00 00 00 1e 00 00 00
0a0: 04 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
100: 01 00 02 00 00 00 00 00 00 00 00 00 30 20 46 00
110: 41 00 00 00 00 20 00 00 00 00 00 00 00 00 00 00
"""  # SYNTHETIC: placeholder vendor ID ABCD, not a real product.

CAP_NAMES = {0x01: "Power Management", 0x05: "MSI", 0x10: "PCI Express",
             0x11: "MSI-X", 0x09: "Vendor Specific", 0x0D: "Bridge Subsys VID"}
ECAP_NAMES = {0x0001: "AER", 0x0002: "Virtual Channel", 0x0003: "Device Serial Number",
              0x000B: "Vendor Specific Ext", 0x000D: "ACS", 0x000E: "ARI",
              0x0010: "SR-IOV", 0x0018: "LTR", 0x0019: "Secondary PCIe",
              0x001E: "L1 PM Substates", 0x0026: "Physical Layer 16.0 GT/s",
              0x0027: "Lane Margining at Receiver"}
SPEED = {1: "2.5 GT/s", 2: "5 GT/s", 3: "8 GT/s", 4: "16 GT/s", 5: "32 GT/s", 6: "64 GT/s"}
PAYLOAD = {i: 128 << i for i in range(6)}          # 000b=128 ... 101b=4096

def parse_hex(text):
    buf = bytearray(4096)
    top = 0
    for line in text.splitlines():
        if ":" not in line:
            continue
        off_s, data = line.split(":", 1)
        try:
            off = int(off_s.strip(), 16)
        except ValueError:
            continue
        vals = [int(x, 16) for x in data.split()]
        buf[off:off + len(vals)] = bytes(vals)
        top = max(top, off + len(vals))
    return bytes(buf[:max(256, top)]), top

u8 = lambda b, o: b[o]
u16 = lambda b, o: struct.unpack_from("<H", b, o)[0]
u32 = lambda b, o: struct.unpack_from("<I", b, o)[0]

def decode_header(b):
    print(f"Vendor:Device      {u16(b,0):04x}:{u16(b,2):04x}")
    cmd, sts = u16(b, 4), u16(b, 6)
    print(f"Command  {cmd:04x}   MemSpace={cmd>>1&1} BusMaster={cmd>>2&1} INTxDisable={cmd>>10&1}")
    print(f"Status   {sts:04x}   CapList={sts>>4&1} MasterAbort={sts>>13&1} SERR={sts>>14&1} ParityErr={sts>>15&1}")
    cls = (b[11], b[10], b[9])
    note = " (Mass storage / NVM / NVMe I/O controller)" if cls == (1, 8, 2) else ""
    print(f"Class    {cls[0]:02x}{cls[1]:02x}{cls[2]:02x}{note}   Rev {b[8]:02x}")
    htype = b[0x0E]
    print(f"Header type {htype & 0x7f} multifunction={htype >> 7}")
    if htype & 0x7f != 0:
        print("Not a Type 0 header (bridge?) - BAR decode below covers BAR0/1 only")
    i = 0
    while i < 6:
        raw = u32(b, 0x10 + 4 * i)
        if raw == 0:
            i += 1
            continue
        if raw & 1:
            print(f"BAR{i}: I/O  0x{raw & ~3:x}")
            i += 1
            continue
        typ = (raw >> 1) & 3
        pref = (raw >> 3) & 1
        addr = raw & ~0xF
        if typ == 2:
            addr |= u32(b, 0x14 + 4 * i) << 32
            print(f"BAR{i}/{i+1}: 64-bit memory 0x{addr:x} prefetchable={pref}")
            i += 2
        else:
            print(f"BAR{i}: 32-bit memory 0x{addr:x} prefetchable={pref}")
            i += 1
    print("(BAR *size* is NOT in config space dumps: sizing needs a write of all-1s,"
          " which this script deliberately never does. Use `lspci -vv` or sysfs resource.)")

def walk_caps(b):
    ptr, seen, caps = b[0x34] & 0xFC, set(), {}
    while ptr and ptr not in seen and ptr < 256:
        seen.add(ptr)
        cid, nxt = b[ptr], b[ptr + 1] & 0xFC
        caps[cid] = ptr
        print(f"  cap @0x{ptr:02x} id 0x{cid:02x} {CAP_NAMES.get(cid, '?')}  next 0x{nxt:02x}")
        ptr = nxt
    if ptr in seen:
        print("  !! capability loop detected - corrupt dump or broken device")
    return caps

def decode_msix(b, p):
    mc = u16(b, p + 2)
    t, pba = u32(b, p + 4), u32(b, p + 8)
    print(f"MSI-X: vectors={(mc & 0x7FF) + 1} enable={mc >> 15} function_mask={mc >> 14 & 1}"
          f" table=BAR{t & 7}+0x{t & ~7:x} PBA=BAR{pba & 7}+0x{pba & ~7:x}")

def decode_pcie(b, p):
    pcap = u16(b, p + 2)
    print(f"PCIe cap version {pcap & 0xF}, device/port type {pcap >> 4 & 0xF}")
    devcap, devctl = u32(b, p + 4), u16(b, p + 8)
    print(f"DevCap  MPS supported {PAYLOAD[devcap & 7]} B")
    print(f"DevCtl  MPS={PAYLOAD[devctl >> 5 & 7]} B  MRRS={PAYLOAD[devctl >> 12 & 7]} B"
          f"  RelaxedOrd={devctl >> 4 & 1} NoSnoop={devctl >> 11 & 1} ErrReportEn={devctl & 0xF:04b}")
    lcap, lsta = u32(b, p + 0x0C), u16(b, p + 0x12)
    mspd, mw = lcap & 0xF, lcap >> 4 & 0x3F
    cspd, cw = lsta & 0xF, lsta >> 4 & 0x3F
    print(f"LnkCap  max {SPEED.get(mspd, mspd)} x{mw}   ASPM support={lcap >> 10 & 3:02b}")
    print(f"LnkSta  now {SPEED.get(cspd, cspd)} x{cw}   training={lsta >> 11 & 1} slotclk={lsta >> 12 & 1}")
    lctl2 = u16(b, p + 0x30)
    print(f"LnkCtl2 target speed {SPEED.get(lctl2 & 0xF, lctl2 & 0xF)}")
    if cspd < mspd or cw < mw:
        print("  !! DOWNGRADED vs device capability. Next: compare with the PORT above"
              " (its LnkCap may be the limit), slot wiring, retimer, LTSSM history.")
    dctl2 = u16(b, p + 0x28)
    print(f"DevCtl2 completion-timeout value field={dctl2 & 0xF:x}h disable={dctl2 >> 4 & 1}")

UNCOR = {4: "DLP", 5: "SurpriseDown", 12: "PoisonedTLP", 13: "FCP", 14: "CmpltTO",
         15: "CmpltAbrt", 16: "UnxCmplt", 17: "RxOverflow", 18: "MalfTLP",
         19: "ECRC", 20: "UnsupReq", 21: "ACSViol"}
CORR = {0: "RxErr", 6: "BadTLP", 7: "BadDLLP", 8: "Rollover", 12: "Timeout",
        13: "AdvNonFatalErr", 14: "CorrIntErr", 15: "HdrLogOvfl"}

def bits(v, names):
    return [n for bit, n in names.items() if v >> bit & 1] or ["-"]

def walk_ecaps(b):
    if len(b) <= 256:
        print("Extended space not in dump (use lspci -xxxx as root)")
        return
    ptr, seen = 0x100, set()
    while ptr and ptr not in seen and ptr + 4 <= len(b):
        seen.add(ptr)
        hdr = u32(b, ptr)
        if hdr in (0, 0xFFFFFFFF):
            break
        eid, ver, nxt = hdr & 0xFFFF, hdr >> 16 & 0xF, hdr >> 20
        print(f"  ecap @0x{ptr:03x} id 0x{eid:04x} v{ver} {ECAP_NAMES.get(eid, '?')}")
        if eid == 0x0001:
            us, cs = u32(b, ptr + 4), u32(b, ptr + 0x10)
            print(f"    AER UncorrStatus {us:08x} {bits(us, UNCOR)}  sev {u32(b, ptr + 0x0C):08x}")
            print(f"    AER CorrStatus   {cs:08x} {bits(cs, CORR)}  mask {u32(b, ptr + 0x14):08x}")
        ptr = nxt

def main():
    text = open(sys.argv[1]).read() if len(sys.argv) > 1 else SAMPLE
    b, top = parse_hex(text)
    decode_header(b)
    print("Capabilities:")
    caps = walk_caps(b)
    if 0x11 in caps: decode_msix(b, caps[0x11])
    if 0x10 in caps: decode_pcie(b, caps[0x10])
    print("Extended capabilities:")
    walk_ecaps(b)

if __name__ == "__main__":
    main()

It is a hypothesis — the downgrade could also be policy (check LnkCtl2 target and the port's LnkCap). Here LnkCtl2 targets 16 GT/s, so policy is less likely.

🧪 Lab 2 — Decode a TLP header SAFE

Classification: offline parsing. File: lab02_tlp.py.

Objective: decode 3DW/4DW non-Flit TLP headers: Fmt/Type, TC, attributes, TD, EP, Length, Requester/Completer IDs, 10-bit Tag, byte enables, address, completion status, byte count, lower address. Flag obvious malformations.

Key ideas: header DWs are transmitted big-endian (byte 0 is the most significant byte of DW0 as conventionally printed); Length = 0 encodes 1024 DW; Tag bits 9 and 8 live in DW0 byte 1 (T9 at bit 23, T8 at bit 19) when 10-bit tags are enabled; a memory request whose upper address DW is zero must use the 3DW format; 1-DW requests must have Last DW BE = 0000b. verified for the PCIe non-Flit header layout. Gen6 Flit-mode TLPs use a different header format and are not handled.

#!/usr/bin/env python3
"""Lab 2 - Decode a PCIe TLP header (OFFLINE PARSING, non-Flit / Gen1-5 format).

Input: header DWs as big-endian hex words, exactly as most analyzers and the
AER "TLP Header:" log line present them (byte 0 = most significant byte of DW0).
Flit-mode (Gen6) headers use a different layout and are NOT handled here.
"""
import sys

FMT = {0: "3DW no data", 1: "4DW no data", 2: "3DW with data", 3: "4DW with data", 4: "TLP prefix"}
CPL_STATUS = {0: "SC (Successful)", 1: "UR (Unsupported Request)",
              2: "CRS (Config Request Retry)", 4: "CA (Completer Abort)"}

def tlp_kind(fmt, typ):
    if typ == 0b00000: return "MRd" if fmt in (0, 1) else "MWr"
    if typ == 0b00001: return "MRdLk"
    if typ == 0b00010: return "IORd" if fmt == 0 else "IOWr"
    if typ == 0b00100: return "CfgRd0" if fmt == 0 else "CfgWr0"
    if typ == 0b00101: return "CfgRd1" if fmt == 0 else "CfgWr1"
    if typ == 0b01010: return "Cpl" if fmt == 0 else "CplD"
    if typ == 0b01011: return "CplLk" if fmt == 0 else "CplDLk"
    if typ >> 3 == 0b10: return "Msg" if fmt in (0, 1) else "MsgD"
    return f"?type={typ:05b}"

def bdf(rid):
    return f"{rid >> 8:02x}:{rid >> 3 & 0x1f:02x}.{rid & 7}"

def decode(dws):
    d0 = dws[0]
    fmt, typ = d0 >> 29 & 7, d0 >> 24 & 0x1F
    t9, tc, t8 = d0 >> 23 & 1, d0 >> 20 & 7, d0 >> 19 & 1
    attr2, th = d0 >> 18 & 1, d0 >> 16 & 1
    td, ep, attr, at = d0 >> 15 & 1, d0 >> 14 & 1, d0 >> 12 & 3, d0 >> 10 & 3
    length = d0 & 0x3FF or 1024           # 0 encodes 1024 DW
    kind = tlp_kind(fmt, typ)
    out = {"kind": kind, "fmt": FMT.get(fmt, "?"), "TC": tc, "TD(ECRC)": td,
           "EP(poisoned)": ep, "RO": attr >> 1 & 1, "NS": attr & 1, "IDO": attr2,
           "TH": th, "AT": at}
    if fmt & 2 or kind in ("MRd", "MRdLk", "IORd", "CfgRd0", "CfgRd1"):
        out["length_DW"] = length
    hdr_dw = 4 if fmt in (1, 3) else 3
    if len(dws) < hdr_dw:
        raise ValueError(f"need {hdr_dw} DWs, got {len(dws)}")
    d1, d2 = dws[1], dws[2]
    if kind.startswith(("MRd", "MWr", "IO", "Cfg")):
        tag = (t9 << 9) | (t8 << 8) | (d1 >> 8 & 0xFF)
        fbe, lbe = d1 & 0xF, d1 >> 4 & 0xF
        out.update(requester=bdf(d1 >> 16), tag=tag, first_BE=f"{fbe:04b}", last_BE=f"{lbe:04b}")
        if kind.startswith("Cfg"):
            out.update(target=bdf(d2 >> 16), reg=f"0x{d2 & 0xFFC:03x}")
        else:
            addr = ((d2 << 32) | (dws[3] & ~3)) if hdr_dw == 4 else (d2 & ~3)
            out["address"] = f"0x{addr:x}"
            if hdr_dw == 4 and d2 == 0:
                out["WARNING"] = "4DW header with addr[63:32]=0 is not allowed for memory requests (malformed)"
            # byte count actually transferred (for MRd/MWr)
            if length == 1:
                out["note"] = "1-DW request: last_BE must be 0000"
                if lbe != 0:
                    out["WARNING"] = "length==1 but Last DW BE != 0 (malformed)"
    elif kind.startswith("Cpl"):
        out.update(completer=bdf(d1 >> 16), status=CPL_STATUS.get(d1 >> 13 & 7, "reserved"),
                   BCM=d1 >> 12 & 1, byte_count=(d1 & 0xFFF) or 4096,
                   requester=bdf(d2 >> 16),
                   tag=(t9 << 9) | (t8 << 8) | (d2 >> 8 & 0xFF),
                   lower_addr=f"0x{d2 & 0x7F:02x}")
    elif kind.startswith("Msg"):
        out.update(requester=bdf(d1 >> 16), msg_code=f"0x{d1 & 0xFF:02x}", routing=f"{typ & 7:03b}")
    return out

EXAMPLES = {  # SYNTHETIC headers built for teaching
    "upstream data write (NVMe read data to host)": "60000040 01000eff 00000001 2a3b4000",
    "SQE fetch read, 64 B, 64-bit address":       "20000010 01002aff 00000001 10010080",
    "completion with data for tag 0x2a":          "4a000010 00000040 01002a00",
    "UR completion":                               "0a000000 00002004 01003100",
    "poisoned write":                              "40004001 0000000f fe601008",
}

if __name__ == "__main__":
    items = {"argv": " ".join(sys.argv[1:])} if len(sys.argv) > 1 else EXAMPLES
    for name, hexs in items.items():
        dws = [int(x, 16) for x in hexs.split()]
        print(f"== {name}: {hexs}")
        quiet = {"TC", "TD(ECRC)", "EP(poisoned)", "RO", "NS", "IDO", "TH", "AT"}
        fields = [f"{k}={v}" for k, v in decode(dws).items() if not (k in quiet and v == 0)]
        print("   " + ", ".join(fields))

🧪 Lab 3 — Parse an NVMe command (SQE) SAFE

Classification: offline parsing. File: lab03_sqe.py (also used as a library by Labs 6–9).

Objective: decode the 64-byte SQE: CDW0 (opcode 7:0, FUSE 9:8, PSDT 15:14, CID 31:16), NSID, MPTR, PRP1/PRP2 (DPTR, bytes 24–39), CDW10–15; derive SLBA, NLB (0-based!) and byte count for I/O commands; flag destructive opcodes.

#!/usr/bin/env python3

#!/usr/bin/env python3
"""Lab 4 - Decode a 16-byte NVMe Completion Queue Entry (OFFLINE PARSING)."""
import struct, sys

GENERIC_SC = {0x00: "Successful Completion", 0x01: "Invalid Command Opcode",
              0x02: "Invalid Field in Command", 0x03: "Command ID Conflict",
              0x04: "Data Transfer Error", 0x06: "Internal Error",
              0x07: "Command Abort Requested", 0x0B: "Invalid Namespace or Format",
              0x13: "Invalid PRP Offset", 0x80: "LBA Out of Range",
              0x81: "Capacity Exceeded", 0x82: "Namespace Not Ready"}
MEDIA_SC = {0x80: "Write Fault", 0x81: "Unrecovered Read Error",
            0x85: "Compare Failure", 0x86: "Access Denied"}
SCT = {0: "Generic", 1: "Command Specific", 2: "Media & Data Integrity",
       3: "Path Related", 7: "Vendor Specific"}

def build_cqe(cid, sqid, sqhd, phase=1, sc=0, sct=0, dnr=0, more=0, dw0=0):
    status = sc | (sct << 8) | (more << 13) | (dnr << 14)   # 15-bit Status Field (DW3[31:17])
    dw3 = cid | (phase << 16) | (status << 17)
    return struct.pack("<IIII", dw0, 0, sqhd | (sqid << 16), dw3)

def parse_cqe(raw):
    dw0, dw1, dw2, dw3 = struct.unpack("<IIII", raw)
    sc, sct = dw3 >> 17 & 0xFF, dw3 >> 25 & 7
    table = MEDIA_SC if sct == 2 else GENERIC_SC if sct == 0 else {}
    return {"dw0": f"0x{dw0:08x}", "sqhd": dw2 & 0xFFFF, "sqid": dw2 >> 16,
            "cid": dw3 & 0xFFFF, "phase": dw3 >> 16 & 1,
            "sct": f"{sct} {SCT.get(sct, 'reserved')}",
            "sc": f"0x{sc:02x} {table.get(sc, '(see spec table)')}",
            "crd": dw3 >> 28 & 3, "more": dw3 >> 30 & 1, "dnr": dw3 >> 31 & 1,
            "ok": sc == 0 and sct == 0}

def is_new(raw, expected_phase):
    """Host-side rule: an entry is new only if its phase tag equals the phase
    the host currently expects; the expected phase flips on each CQ wrap."""
    return parse_cqe(raw)["phase"] == expected_phase

#include <stdio.h>
#include <stdint.h>
#include <string.h>

static int hexbyte(const char *s, uint8_t *out) {
    unsigned v;
    if (sscanf(s, "%2x", &v) != 1) return -1;
    *out = (uint8_t)v;
    return 0;
}

int main(int argc, char **argv) {
    uint8_t b[16];
    uint32_t dw[4];

        fprintf(stderr, "usage: %s <32 hex chars>\n", argv[0]);
        return 2;
    }
    for (int i = 0; i < 16; i++)
        if (hexbyte(argv[1] + 2 * i, &b[i])) { fprintf(stderr, "bad hex\n"); return 2; }
    for (int i = 0; i < 4; i++)
        dw[i] = (uint32_t)b[4*i] | (uint32_t)b[4*i+1] << 8 |

🧪 Lab 5 — Interpret PRP addresses SAFE

Classification: simulation (fake host memory). File: lab05_prp.py.

Objective: compute the exact list of (address, length) DMA segments a controller derives from PRP1, PRP2 and a transfer length — including PRP lists and chained list pages — and detect invalid PRPs.

Key ideas: PRP1 may have a dword-aligned offset; all subsequent data PRP entries must be page-aligned (offset 0) with page size from CC.MPS; when the transfer needs more than two pages PRP2 is a PRP list pointer; the last entry of a full list page points to the next list page. Whether the controller reports Invalid PRP Offset, Data Transfer Error or something else for a specific violation is defined by the specification's status rules and controller behavior — consult the spec for the exact code impl.

#!/usr/bin/env python3
"""Lab 5 - Interpret PRP addresses (SIMULATION on a fake host memory dict).
Implements the PRP rules for a transfer of `length` bytes with memory page
size `mps` (CC.MPS, typically 4 KiB):
  * PRP1 may carry an offset (dword aligned); it covers up to the page end.
  * If the rest fits in one more page, PRP2 is that page's address.
  * Otherwise PRP2 points to a PRP List; list entries are page-aligned page
    addresses; the LAST slot of a full list page chains to the next list page.
"""
import struct

class FakeHostMemory:
    def __init__(self):
        self.qwords = {}
    def write_list(self, addr, entries):
        for i, e in enumerate(entries):
            self.qwords[addr + 8 * i] = e
    def read_qword(self, addr):
        if addr not in self.qwords:
            raise LookupError(f"controller would DMA-read unmapped 0x{addr:x}")
        return self.qwords[addr]

def walk_prps(prp1, prp2, length, mem, mps=4096):
    """Return [(addr, nbytes)] the controller would DMA, or raise on violation."""
    if prp1 & 3:
        raise ValueError("PRP1 must be dword aligned")
    off = prp1 & (mps - 1)
    first = min(length, mps - off)
    segs, remaining = [(prp1, first)], length - first
    if remaining == 0:
        return segs
    if remaining <= mps:                       # exactly two pages: PRP2 is a page
        if prp2 & (mps - 1):
            raise ValueError("PRP2 used as data page must have zero offset (Invalid PRP Offset)")
        return segs + [(prp2, remaining)]
    if prp2 & 7:
        raise ValueError("PRP list pointer must be qword aligned")
    entries_per_page = mps // 8
    ptr = prp2
    slot = (ptr & (mps - 1)) // 8              # list may start mid-page
    while remaining:
        entry = mem.read_qword(ptr)
        last_slot = slot == entries_per_page - 1
        if last_slot and remaining > mps:      # chain to the next list page
            ptr, slot = entry, 0
            continue
        if entry & (mps - 1):
            raise ValueError(f"PRP entry 0x{entry:x} has non-zero offset")
        n = min(mps, remaining)
        segs.append((entry, n))
        remaining -= n
        ptr += 8
        slot += 1
    return segs

def demo(title, prp1, prp2, length, mem, mps=4096):
    print(f"--- {title}: length={length} prp1=0x{prp1:x} prp2=0x{prp2:x}")
    try:
        for a, n in walk_prps(prp1, prp2, length, mem, mps):
            print(f"    DMA 0x{a:010x} .. +{n}")
    except (ValueError, LookupError) as e:
        print("    ERROR:", e)

Trace view: on the link, a PRP list shows up as an extra MRd from the SSD (reading the list from host memory) before the data MWr (for a Read) or data MRd (for a Write). A 20 KiB read therefore has: SQE fetch MRd/CplD, PRP list MRd/CplD (32 bytes for 4 entries), then 20 KiB of data MWr. If the list pointer is bad, you see the list MRd answered by a UR/CA completion, or a DMA fault logged by the IOMMU — and no data.

Questions: (1) Why does a 4 KiB transfer with PRP1 offset 0x200 need PRP2? (2) How many list pages does a 2.1 MiB transfer need with 4 KiB pages? (3) A trace shows data MWr to the right pages but one page is shifted by 0x100. Which PRP rule might the host have violated?

Solution

(1) Only 4096 − 0x200 = 3584 bytes fit before the page boundary; the remaining 512 bytes go to the page named by PRP2. (2) 541 pages: PRP1 covers one; 540 entries remain; the first list page holds 511 data entries plus one chain pointer, the second holds the remaining 29 — two list pages. (3) A non-first PRP entry with a non-zero offset; a conforming controller should reject it, a non-conforming one may DMA to the wrong place — data corruption with "successful" status. Verify with the PRP list contents (MRd/CplD payload) in the trace.

Quiz

  1. Why must an SQE decoder add 1 to CDW12[15:0]?

    Answer

    NLB is a 0-based value: 0 means one logical block.

  2. Which two fields correlate a PCIe completion to its request?

    Answer

    Requester ID and Tag (the completion echoes both; it carries the Completer ID too, but matching uses Requester ID + Tag).

  3. Why can BAR sizes not be extracted from an lspci -xxxx dump?

    Answer

    The size is discovered by writing all-ones and reading back the mask; a dump only contains the programmed base address. The kernel records sizes during enumeration and exposes them via lspci -vv and sysfs resource.

  4. What is the phase tag of the first pass through a freshly created CQ?

    Answer

    The host initializes CQ memory with phase 0 entries (zeroed), and the controller writes phase 1 on the first pass; the host expects 1 first.

73.1 Why this chapter exists

Decoding one TLP is a skill; reconstructing an NVMe command from forty TLPs interleaved with thirty others is the job. This chapter builds a small, honest version of what protocol analyzers call a "transaction view" and what debug engineers do in their heads: group link events into commands, measure each phase, and find where a command's chain broke.

  • Beginner: read a normalized TLP event table and point at doorbell, SQE fetch, data, CQE and interrupt.
  • Intermediate: build per-command phase timelines and correlate by (SQID, CID).
  • Advanced: classify missing completions by the furthest stage reached; separate PCIe completion timeout from NVMe command timeout.
  • Senior: account for capture coverage (capture end, filtering, interrupt coalescing) before declaring anything "missing".
  • Validation: run these detectors over every capture in a regression suite.

73.2 Shared model: trace_common.py (queue simulator S8)

"""trace_common.py - shared SYNTHETIC trace model for Labs 6-9 (SIMULATION).

  t_ns, dir ('DN' = host->device, 'UP' = device->host), kind, addr, nbytes, tag, payload

from dataclasses import dataclass

@dataclass

    kind: str

    nbytes: int = 0

def sq_tail_db(qid):  return BAR0 + 0x1000 + (2 * qid) * (4 << DSTRD)
def cq_head_db(qid):  return BAR0 + 0x1000 + (2 * qid + 1) * (4 << DSTRD)

def classify(ev, qid=1):
    """Turn an address into an NVMe meaning - the core of NVMe-over-PCIe trace reading."""
    a = ev.addr
    if ev.kind == "MWr" and a == sq_tail_db(qid):   return "SQ%d tail doorbell" % qid
    if ev.kind == "MWr" and a == cq_head_db(qid):   return "CQ%d head doorbell" % qid
    if ev.kind == "MRd" and SQ_BASE <= a < SQ_BASE + 64 * QSIZE:
        return "SQE fetch slot %d" % ((a - SQ_BASE) // 64)
    if ev.kind == "MWr" and CQ_BASE <= a < CQ_BASE + 16 * QSIZE:
        return "CQE post slot %d" % ((a - CQ_BASE) // 16)
    if ev.kind == "MWr" and a & ~0xFFFFF == MSIX_ADDR: return "MSI-X interrupt"
    if ev.kind == "MWr" and ev.dir == "UP":         return "data to host (read payload)"
    if ev.kind == "CplD":                           return "completion with data"
    return "other"

🧪 Lab 6 — Build an NVMe transaction timeline SAFE

Classification: offline / simulation. File: lab06_timeline.py.

Objective: group TLPs into per-command transactions and compute phase durations: doorbell→fetch, fetch→SQE arrival, SQE→first data (≈ controller + media time), data duration, data→CQE, CQE→interrupt.

#!/usr/bin/env python3
"""Lab 6 - Build an NVMe transaction timeline from TLP events (OFFLINE / SIMULATION).
Groups TLPs into per-command transactions using ONLY information visible on
the link: doorbell writes, SQE-fetch MRd + tag-matched CplD (whose payload
is the SQE), data MWr addresses matched to PRP1, CQE payloads, MSI-X writes."""
from trace_common import gen_trace, classify, Ev, SQ_BASE, CQ_BASE, MSIX_ADDR
from lab03_sqe import parse_sqe
from lab04_cqe import parse_cqe

def build_timeline(evs):
    pending_mrd = {}            # tag -> MRd event (SQE fetch)
    cmds = {}                   # (sqid, cid) -> dict of phase timestamps
    by_buf = {}                 # PRP1 page -> key
    last_cqe_key, db_t = None, None
    for e in evs:
        role = classify(e)
        if role.startswith("SQ") and "doorbell" in role:
            db_t = e.t_ns
        elif role.startswith("SQE fetch"):
            pending_mrd[e.tag] = (e, db_t)
        elif e.kind == "CplD" and e.tag in pending_mrd:
            mrd, dbt = pending_mrd.pop(e.tag)
            sqe = parse_sqe(e.payload)
            key = (1, sqe["cid"])
            if key in cmds and "cqe" not in cmds[key]:
                cmds[key].setdefault("anomaly", []).append("CID reused while outstanding")
            cmds[key] = {"doorbell": dbt, "fetch": mrd.t_ns, "sqe": e.t_ns,
                         "opcode": sqe["opcode"], "prp1": int(sqe["prp1/sgl"], 16)}
            by_buf[int(sqe["prp1/sgl"], 16) & ~0xFFF] = key
        elif role.startswith("data"):
            key = by_buf.get(e.addr & ~0xFFF)
            if key:
                c = cmds[key]
                c.setdefault("data_first", e.t_ns)
                c["data_last"] = e.t_ns
                c["bytes"] = c.get("bytes", 0) + e.nbytes
        elif role.startswith("CQE"):
            q = parse_cqe(e.payload)
            key = (q["sqid"], q["cid"])
            c = cmds.setdefault(key, {"anomaly": ["CQE for unknown command"]})
            c["cqe"], c["status"] = e.t_ns, q["sc"]
            last_cqe_key = key
        elif role == "MSI-X interrupt" and last_cqe_key:
            cmds[last_cqe_key].setdefault("irq", e.t_ns)
    return cmds, pending_mrd

🧪 Lab 8 — Detect a missing completion SAFE

Classification: offline / simulation. File: lab08_missing.py.

Objective: for every command that never fully completed, report the furthest stage reached and what that implies; refuse to conclude when the capture ended too soon.

#!/usr/bin/env python3
"""Lab 8 - Detect a missing NVMe completion and say WHERE the chain broke.
Classification uses the furthest stage reached on the link. The capture end
time matters: a command submitted 5 us before capture end is not 'missing'."""
from trace_common import gen_trace
from lab06_timeline import build_timeline

STAGES = ["doorbell", "fetch", "sqe", "data_first", "cqe", "irq"]
VERDICT = {
    "fetch": "SQE fetch MRd sent but no CplD: PCIe completion problem (host/RC side or tag loss)",
    "sqe": "SQE delivered but no data/CQE: controller-internal stall (media, FW, or command hang)",
    "data_first": "Data moved but no CQE: controller failed to post completion (FW) or CQ full",
    "cqe": "CQE posted but no MSI-X seen: interrupt path (MSI-X mask/config/coalescing)",
}

def find_missing(evs, capture_end_ns, grace_ns=1_000_000):
    cmds, orphan_tags = build_timeline(evs)
    report = []
    for key, c in cmds.items():
        if "cqe" in c and "irq" in c:
            continue
        reached = [s for s in STAGES if s in c][-1]
        age = capture_end_ns - c.get("doorbell", 0)
        if age < grace_ns:
            report.append((key, "INCONCLUSIVE - submitted too close to capture end"))
        else:
            report.append((key, f"stopped after '{reached}': {VERDICT.get(reached, '?')}"))
    for tag, (mrd, _) in orphan_tags.items():
        report.append((("?", "?"), f"MRd tag {tag:#x} @ {mrd.t_ns/1e3:.3f}us never completed; "
                                   "CID unknown because the SQE never arrived"))
    return report

    end = evs[-1].t_ns + 5_000_000           # capture kept running 5 ms after last TLP
    for key, msg in find_missing(evs, end):

🧪 Lab 9 — Detect a completion timeout SAFE

Classification: offline / simulation. File: lab09_cpl_timeout.py.

Objective: track every Non-Posted request by (Requester ID, Tag), accumulate partial completions until the byte count is satisfied, flag tag reuse, unexpected completions and requests older than a timeout; separately age NVMe commands against the host io_timeout.

#!/usr/bin/env python3
"""Lab 9 - Detect PCIe completion timeouts and NVMe command timeouts (OFFLINE).
Two different clocks, two different owners:
  * PCIe Completion Timeout: a Non-Posted request (MRd) whose CplD does not
    return within the requester's configured range (Device Control 2). The
    REQUESTER (here: the SSD fetching an SQE or write data) detects it.
  * NVMe command timeout: the HOST driver's timer (Linux nvme_core io_timeout,
    default 30 s) on a submitted command with no CQE.
Matching key for PCIe completions: (Requester ID, Tag). Tags may be reused
only after the previous request with that tag has fully completed."""
from trace_common import gen_trace, Ev

def pcie_completion_check(evs, timeout_ns=50_000_000, requester="01:00.0"):
    open_tags, findings, lat = {}, [], []
    for e in evs:
        if e.kind == "MRd" and e.dir == "UP":
            if e.tag in open_tags:
                findings.append(f"t={e.t_ns/1e3:.3f}us tag {e.tag:#x} REUSED while outstanding "
                                f"(protocol violation by requester)")
            open_tags[e.tag] = {"t": e.t_ns, "want": e.nbytes, "got": 0}
        elif e.kind in ("CplD", "Cpl") and e.dir == "DN":
            o = open_tags.get(e.tag)
            if o is None:
                findings.append(f"t={e.t_ns/1e3:.3f}us Unexpected Completion tag {e.tag:#x}")
                continue
            o["got"] += e.nbytes
            if o["got"] >= o["want"]:
                lat.append(e.t_ns - o["t"])
                del open_tags[e.tag]
    end = evs[-1].t_ns
    for tag, o in open_tags.items():
        age = end - o["t"]
        state = "TIMED OUT" if age > timeout_ns else f"open {age/1e3:.1f}us (< timeout, inconclusive)"
        findings.append(f"tag {tag:#x} MRd @ {o['t']/1e3:.3f}us {state}; got {o['got']}/{o['want']} B")
    return lat, findings

def nvme_timeout_check(cmd_submit_ns, cmd_cqe_ns, now_ns, io_timeout_s=30):
    out = []
    for key, t0 in cmd_submit_ns.items():
        t1 = cmd_cqe_ns.get(key, now_ns)       # no CQE yet: age it against "now"
        if (t1 - t0) > io_timeout_s * 1e9:
            out.append((key, (t1 - t0) / 1e9))
    return out

📘 Specification

The PCIe Completion Timeout mechanism and its programmable ranges are configured through Device Control 2 (value field bits 3:0, disable bit 4) with supported ranges advertised in Device Capabilities 2. The default range is commonly described as 50 µs to 50 ms confirm the exact wording in your PCIe Base Specification revision. A completion may legally be split into several CplDs (at Read Completion Boundary multiples); a detector must sum byte counts rather than expect exactly one completion per request — as this lab does.

Questions: (1) Which agent detects a PCIe Completion Timeout and which agent detects an NVMe I/O timeout? (2) Why does a PCIe completion timeout on an SQE fetch eventually surface as an NVMe timeout? (3) Why does the lab treat an open request younger than the timeout as "inconclusive"?

Solution

(1) The PCIe requester (here the SSD) detects completion timeout and may report it via AER; the host driver detects NVMe command timeouts with its own timer. (2) Without the SQE, the controller cannot execute the command and never posts a CQE; the host's io_timeout (default 30 s) eventually fires. Expect AER CmpltTO from the SSD, then ~30 s later an NVMe timeout — as in Chapter 71's sample. (3) Capture end is not proof of absence; the completion may arrive after the capture stopped.

Extension: model the Read Completion Boundary: split each CplD into 64- or 128-byte pieces and verify Lower Address and Byte Count progress correctly.

🧪 Lab 10 — Analyze AER logs SAFE

Classification: offline parsing of saved log text. File: lab10_aer.py.

Objective: extract AER events from kernel logs, decode status registers into named bits and layers, count per device, find the first uncorrectable error and what preceded it — while explicitly refusing to equate "preceded" with "caused".

#!/usr/bin/env python3
"""Lab 10 - Analyze AER logs (OFFLINE PARSING of saved kernel log text).
Usage:  journalctl -k -b > kern.txt   (read-only)   ;  python3 lab10_aer.py kern.txt
The parser is deliberately tolerant: AER message wording differs across
kernel versions, so it keys on stable fragments ("severity=", "type=",
"error status/mask=") and reports lines it could not classify."""
import re, sys
from collections import Counter, defaultdict

UNCOR = {4: "Data Link Protocol", 5: "Surprise Down", 12: "Poisoned TLP",
         13: "Flow Control Protocol", 14: "Completion Timeout", 15: "Completer Abort",
         16: "Unexpected Completion", 17: "Receiver Overflow", 18: "Malformed TLP",
         19: "ECRC", 20: "Unsupported Request", 21: "ACS Violation"}
CORR = {0: "Receiver Error", 6: "Bad TLP", 7: "Bad DLLP", 8: "REPLAY_NUM Rollover",
        12: "Replay Timer Timeout", 13: "Advisory Non-Fatal", 14: "Corrected Internal",
        15: "Header Log Overflow"}
LAYER = {"Receiver Error": "Physical", "Bad TLP": "Data Link", "Bad DLLP": "Data Link",
         "REPLAY_NUM Rollover": "Data Link", "Replay Timer Timeout": "Data Link",
         "Data Link Protocol": "Data Link", "Surprise Down": "Data Link/Physical",
         "Completion Timeout": "Transaction", "Unsupported Request": "Transaction",
         "Poisoned TLP": "Transaction", "Malformed TLP": "Transaction",
         "Completer Abort": "Transaction", "Unexpected Completion": "Transaction",
         "ECRC": "Transaction", "Receiver Overflow": "Transaction",
         "Flow Control Protocol": "Data Link"}

SAMPLE = """\
[  812.112233] pcieport 0000:00:1c.0: AER: Corrected error received: 0000:01:00.0
[  812.112240] nvme 0000:01:00.0: PCIe Bus Error: severity=Corrected, type=Physical Layer, (Receiver ID)
[  812.112244] nvme 0000:01:00.0:   device [abcd:0001] error status/mask=00000001/00002000
[  812.112248] nvme 0000:01:00.0:    [ 0] RxErr
[  815.400101] pcieport 0000:00:1c.0: AER: Corrected error received: 0000:01:00.0
[  815.400110] nvme 0000:01:00.0: PCIe Bus Error: severity=Corrected, type=Data Link Layer, (Transmitter ID)
[  815.400114] nvme 0000:01:00.0:   device [abcd:0001] error status/mask=00001000/00002000
[  901.000500] pcieport 0000:00:1c.0: AER: Uncorrected (Non-Fatal) error received: 0000:01:00.0
[  901.000510] nvme 0000:01:00.0: PCIe Bus Error: severity=Uncorrected (Non-Fatal), type=Transaction Layer, (Requester ID)
[  901.000514] nvme 0000:01:00.0:   device [abcd:0001] error status/mask=00004000/00000000
[  901.000520] nvme 0000:01:00.0:    [14] CmpltTO
[  931.100000] nvme nvme0: I/O tag 23 (1017) opcode 0x2 (Read) QID 3 timeout, aborting
"""  # SYNTHETIC, written to resemble common Linux AER/NVMe log shapes; wording varies by kernel.

TS = re.compile(r"^\[\s*(\d+\.\d+)\]")
DEV = re.compile(r"(\d{4}:[0-9a-f]{2}:[0-9a-f]{2}\.[0-7])")
STAT = re.compile(r"error status/mask=([0-9a-f]{8})/([0-9a-f]{8})")
SEV = re.compile(r"severity=([^,]+), type=([^,]+)")

def decode(status, mask, uncorrectable):
    table = UNCOR if uncorrectable else CORR
    return [(table.get(b, f"bit{b}"), bool(mask >> b & 1)) for b in range(32) if status >> b & 1]

def analyze(text):
    events, unknown, sev, last_ts = [], [], None, None
    per_dev = defaultdict(Counter)
    for line in text.splitlines():
        m = TS.search(line)
        ts = float(m.group(1)) if m else None
        if (s := SEV.search(line)):
            sev = s.group(1)
            continue
        if (s := STAT.search(line)):
            dev = DEV.search(line).group(1)
            st, mk = int(s.group(1), 16), int(s.group(2), 16)
            unc = sev is not None and sev.startswith("Uncorrected")
            for name, masked in decode(st, mk, unc):
                layer = LAYER.get(name, "?")
                events.append((ts, dev, sev, name, layer, masked))
                per_dev[dev][name] += 1
            continue
        if "timeout" in line and "nvme" in line:
            events.append((ts, "nvme", "driver", "NVMe command timeout", "NVMe/driver", False))
        elif "AER" in line or "PCIe Bus Error" in line:
            continue
        elif line.strip() and not re.search(r"\]\s+\S+ \S+:\s+\[\s*\d+\]", line):
            unknown.append(line)
    return events, per_dev, unknown

if __name__ == "__main__":
    text = open(sys.argv[1]).read() if len(sys.argv) > 1 else SAMPLE
    events, per_dev, unknown = analyze(text)
    for ts, dev, sev, name, layer, masked in events:
        print(f"{ts:10.3f}  {dev:14s} {str(sev):26s} {name:22s} layer={layer}{' (masked bit set)' if masked else ''}")
    first_unc = next((e for e in events if e[2] and str(e[2]).startswith("Uncorrected")), None)
    if first_unc:
        prior = [e for e in events if e[0] < first_unc[0]]
        print(f"\nFirst uncorrectable at {first_unc[0]:.3f}s: {first_unc[3]}; "
              f"{len(prior)} earlier corrected event(s) - correlation, not proof of causation.")
    print("Per-device counts:", {d: dict(c) for d, c in per_dev.items()})
    if unknown:
        print("Unclassified lines (review by hand):", *unknown, sep="\n  ")

Quiz

  1. Where does the SQE appear on the PCIe link?

    Answer

    As the payload of a CplD flowing host→device in answer to the controller's MRd of the SQ slot.

  2. A CQE MWr is present but the host times out. Name two link-visible checks.

    Answer

    Is there an MSI-X MWr after it (to the right address/data)? Did the CQE land in the CQ slot the host expects with the right phase tag?

  3. Why must completion matching sum byte counts?

    Answer

    Completers may split a read into multiple CplDs; the request is satisfied only when all bytes have returned.

Interview questions

  1. Intermediate Describe how you would reconstruct an NVMe read from a PCIe trace.
    Model answer

    Find the SQ tail doorbell MWr; find the controller's MRd to the SQ slot and the matching CplD by tag; parse the SQE (opcode, CID, PRP, LBA); find PRP list fetches if any; find data MWr to the PRP pages; find the CQE MWr in the CQ ring with matching SQID/CID and phase; find the MSI-X MWr; find the host's CQ head doorbell.

  2. Senior Your missing-completion detector flags 200 commands in a 2-second capture. What do you check before filing a bug?
    Model answer

    Capture coverage: end time vs submission times, active filters (were CQ writes or MSI-X filtered out?), both directions captured, buffer overflow or dropped packets, correct queue base addresses (queues may have been re-created after a reset), interrupt coalescing, polled queues (no MSI-X by design).
