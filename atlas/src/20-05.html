II.5 Complete Status Code Table

Every status code defined in Linux v7.2 include/linux/nvme.h appears below, in Linux's shifted layout (SCT in bits 10:8, SC in bits 7:0). The "Linux string" column is what nvme_get_error_status_str() prints. The errno column follows nvme_error_status() plus blk_errors[]. A dash means the code only occurs on admin/passthrough commands, where nvme-cli gets the raw status and no errno mapping applies. "Retry? (typical)" is what the code usually means for a retry, based on the spec wording and QEMU's DNR use derived. The authoritative signal is always the DNR bit in the actual CQE, and Linux retries anything without DNR (§II.1.4.1). The PEX column says whether the status itself can be read from a PCIe analyzer capture of the SSD link: "Visible" means the CQE is a device→host MWr whose payload holds the status.
