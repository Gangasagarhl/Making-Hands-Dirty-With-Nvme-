This page shows what depends on what, how hard each stage is, and which pages to read in which order for your goal. Read it once before you start and again whenever you feel lost: usually the gap is one stage further back than it seems.

Why a map

Non-Volatile Memory Express (NVMe) over PCI Express (PCIe) is a stack of ideas in which almost every later idea assumes several earlier ones. A completion timeout makes no sense until you know what a non-posted request is. A non-posted request makes no sense until you know what a Transaction Layer Packet (TLP) is. A TLP is meaningless until you know why a device needs to read memory at all. Learners who skip a stage do not fail at that stage. They fail three stages later, with a confusion they cannot locate.

This page gives you three tools:

  • The dependency map: the seventeen stages from computer architecture to senior debugging, the pages that teach each one, and the extra dependencies that cut across stages.
  • The difficulty phases: ten phases from simple analogies to principal-level reasoning. They tell you what kind of material is appropriate now and what to postpone.
  • Reading orders: the full path, and shorter paths for firmware, driver, validation, trace-analysis, architecture and interview goals, plus a placement test to find where you start.

Learning NVMe is like building a tower of blocks. You can put a shiny block on top early, but if a block near the bottom is missing, the whole tower wobbles, and you notice the wobble at the top, not at the gap.

A university degree has prerequisite chains: you cannot take signals and systems before calculus. The course catalogue is a graph, not a list, and good advisors know which shortcuts are safe and which are not.

University prerequisites are enforced by registration. Here nothing stops you opening Chapter 47 first, and some later pages genuinely reward a quick early look (to see where you are heading). The map tells you what you will need, not what you are forbidden to read. And unlike courses, stages here are revisited: you will pass through PCIe ordering three times, at increasing depth.

One concept through all ten phases

Here is the doorbell at every phase, to show what "harder" means. The concept is the same throughout; only the kind of reasoning changes.

  1. Simple analogy. "After you put a slip in the box, you ring a bell."
  2. Simple diagram. An arrow from CPU to SSD labeled "doorbell", after an arrow from CPU to memory labeled "write command".
  3. Registers. SQ1 tail doorbell at BAR0 + 0x1008 when DSTRD = 0; value = new tail index.
  4. Commands. Three SQEs written at slots 2, 3, 4; one doorbell write of 5 publishes all three.
  5. TLPs. The doorbell is a 1-DW posted MWr from the root complex; it needs no completion.
  6. Traces. In a capture, the doorbell MWr is followed about 0.8 µs later by a device MRd for 192 bytes at SQ base + 2 × 64.
  7. Errors. A doorbell value larger than the queue size raises an asynchronous event; the command never runs.
  8. Multi-layer debugging. Commands time out only under load: the trace shows the doorbell arriving before the SQE memory writes became visible (missing barrier), so the device fetched stale entries.
  9. Architecture. For a hypervisor-emulated controller, trapping every doorbell is expensive; shadow doorbells in host memory trade MMIO traps for polling and memory traffic.
  10. Principal-level. A customer reports rare hangs on one platform. The decision is whether to ship a driver workaround (extra barrier, measurable cost) before the root cause is confirmed; it depends on evidence strength, blast radius and reversibility.

Placement test: where should you start?

Answer these twelve questions without looking anything up. Start at the stage of the first question you cannot answer fully. Do not skip ahead past a missed question because later ones felt easy: the map says the gap will catch up with you.

  1. (Stage 1–2) What is the difference between a cache, RAM and an SSD in terms of speed, capacity and volatility?

    Model answer

    Caches are smallest and fastest (nanoseconds or less), RAM is larger and slower (around 100 ns), both are volatile. SSDs are much larger, much slower (tens of µs for a read), and non-volatile.

  2. (Stage 3) How can a CPU store instruction change something inside a device?

    Model answer

    Device registers are mapped into the physical address space (MMIO). A store to that address is routed by the platform to the device as a write transaction instead of to RAM.

  3. (Stage 4) During a disk read by DMA, who writes the data into RAM?

    Model answer

    The device (its DMA engine), via memory write transactions. The CPU does not copy it.

  4. (Stage 5) What is the raw transfer rate of a Gen4 x4 link and why is usable bandwidth lower?

    Model answer

    16 GT/s per lane × 4 lanes; with 128b/130b encoding about 7.88 GB/s per direction before packet overhead. Headers, sequence numbers, LCRC, framing, DLLPs and flow-control behavior reduce usable throughput further.

  5. (Stage 6) Why does a Memory Read request need a tag and a Memory Write request does not?

    Model answer

    A read is non-posted: completions come back later, possibly out of order and split, and the requester must match them to the request. A write is posted: no completion returns, so there is nothing to match.

  6. (Stage 7) What does a BAR do, and how does software find out its size?

    Model answer

    It defines an address window for the device's registers or memory. Software writes all ones, reads back, and the bits that stay zero (above the type bits) reveal the size; then it programs the base address.

  7. (Stage 8) List the steps to enable an NVMe controller.

    Model answer

    Wait for CSTS.RDY = 0 if disabling; allocate admin SQ/CQ; program AQA, ASQ, ACQ; set CC fields (I/O queue entry sizes, memory page size, command set) and CC.EN = 1; wait for CSTS.RDY = 1 within CAP.TO; then Identify and create I/O queues.

  8. (Stage 9) How does the host know a new CQE has arrived without reading a device register?

    Model answer

    It compares the CQE's Phase Tag with the phase it expects for the current lap; a match means the entry is new.

  9. (Stage 10) Which field in an NVMe Read command is zero-based, and what does that mean for NLB = 7?

    Model answer

    Number of Logical Blocks; 7 means eight blocks.

  10. (Stage 11) A 12 KiB transfer starts at offset 0x200 in its first 4 KiB page. How many pages does it touch, and is a PRP list needed?

    Model answer

    0x200 + 0x3000 = 0x3200, which spans four pages (0x0000–0x0FFF, 0x1000–0x1FFF, 0x2000–0x2FFF, 0x3000–0x31FF). More than two pages, so PRP2 points to a PRP list containing three entries.

  11. (Stage 12) In an NVMe Write, in which direction do the data TLPs flow, and what type are they?

    Model answer

    The device issues Memory Read requests to host memory; the data returns host→device in Completion-with-Data TLPs.

  12. (Stages 13–14) An AER log shows a completion timeout reported by the root port. Does that mean the SSD failed?

    Model answer

    No. It means a request issued through the root port got no completion within the timeout. The SSD may have dropped it, been in reset, been unreachable because of a link problem, or the request may have been wrong. The first abnormal event, which may be earlier, decides.

All twelve fully right: start at stage 13 (trace analysis), but read Command vs Packet vs Completion and Common Misconceptions first as a check. Missed questions 1–4: start at the beginning; it will go fast. Missed 5–7: start at Part IV. Missed 8–12: start at Part IX after a quick quiz pass through Parts IV–VIII.
