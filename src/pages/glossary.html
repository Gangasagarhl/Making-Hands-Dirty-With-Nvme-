How to use this glossary

Hover, then follow. Anywhere in the course, a dotted-underlined term opens a short popup with its definition. The popup's link brings you here, and each entry here ends with Learn more links to the chapters (chNN) and deep-dive modules (ddNN) where the term is built up through the full ladder, from story to trace to debugging. A glossary definition is a reminder, not a lesson: if a definition does not make sense yet, follow its first link.

Filter and jump. Type in the filter box below to narrow the list (it matches terms and expansions), or use the letter bar. Terms are sorted by their displayed name, so acronyms appear under their first letter: Transaction Layer Packet (TLP) is under T, Message Signaled Interrupts – Extended (MSI-X) under M.

The forty-two foundation terms that the curriculum requires every learner to master — NVMe, NVM, SSD, NAND, FTL, PCIe, RC, EP, RP, BDF, BAR, MMIO, DMA, TLP, DLLP, LTSSM, ACK, NAK, AER, MSI, MSI-X, SQ, CQ, ASQ, ACQ, CID, NSID, PRP, SGL, LBA, ZNS, KV, SLM, NVMe-MI, NVMe-oF, AIC, U.2, M.2, EDSFF, SR-IOV, PF and VF — carry four views in their entries: the engineering definition, a kid version (the Level A story), where used, and the common confusion that trips people up. If you can say all four views from memory for all forty-two, you have the vocabulary for the most important chapter.

Several abbreviations mean different things in different layers, and confusing them is a classic source of wrong conclusions. AER is PCIe Advanced Error Reporting, but also shorthand for the NVMe Asynchronous Event Request command. MPS is PCIe Max Payload Size in Device Control, and NVMe Memory Page Size in CC. EP is an Endpoint, and the TLP "error poisoned" bit. Completion is a PCIe TLP answering a non-posted request, and a 16-byte NVMe completion queue entry. Queue pair means an NVMe SQ/CQ pair, or an RDMA send/receive queue pair. When an entry has a twin, its definition says so.

How definitions are written. Definitions follow the course's truth policy: register offsets, opcodes and encodings appear only when they are well established (for example CC at 14h, Identify opcode 06h, Fmt 010b for a 3-DWORD header with data). Features new in the NVMe 2.4 set of August 2026 are described by purpose only; their field-level details must be confirmed in the specification itself. Where a meaning depends on revision or implementation, the entry says so.
